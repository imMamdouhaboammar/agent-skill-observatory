## Description

Maintains the Alfred Brain project note lifecycle — reads or creates Projects/ProjectName.md from the vault template when starting work on a project, and updates its Current State section when finishing a session. Use at the start of any work session in a project under _Projects\, and again before ending that session, to keep the vault's cross-session memory current.
