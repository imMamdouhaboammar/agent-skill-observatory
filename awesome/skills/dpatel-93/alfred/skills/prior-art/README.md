## Description

Check whether something has already been built before building it. Searches GitHub via the gh CLI and API — never a browser — then judges each candidate on maintenance, licence and fit, and returns a verdict of ADOPT / ADAPT / BUILD with the evidence. Use before starting any new tool, skill, script, integration or framework; when the user asks "has anyone done this", "is there a library for this", "should we build or borrow"; or when a design is about to commit to a from-scratch implementation.
