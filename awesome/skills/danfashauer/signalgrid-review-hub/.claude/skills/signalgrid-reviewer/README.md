## Description

The adversarial second reviewer for SignalGrid. Use when a change is ready for review, before any push or PR, or when asked to check whether a claim about the repo is true. This role verifies and reports; it never fixes, never authors, and never merges. Covers the repo's known defect classes, how to falsify a guard, and how to write findings the owner can act on without reading code.
