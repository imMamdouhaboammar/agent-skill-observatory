## Description

Use when a fix, optimization, or behavior change is claimed to work and needs fresh evidence, or when the user says "verify this", "prove it", "did this fix it", or "show me the evidence". Restates the claim falsifiably, captures baseline and treatment, and returns VERIFIED, NOT VERIFIED, or INCONCLUSIVE.
