## Description

Generate the Setup and Archive shell scripts for Orca's Worktree Hooks settings for the current repo. Explores the repo to decide which gitignored files to copy, which large data to symlink, and which dependencies to reinstall, then copies the script to the clipboard for pasting into Orca. Use when the user says "orca worktree hooks", "orca setup script", "worktree setup script", or asks how to make new Orca worktrees usable without manual setup.
