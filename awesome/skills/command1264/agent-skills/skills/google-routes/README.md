## Description

使用 Google Routes API 查詢明確起點、終點與未來出發時間的汽車或機車路線，並輸出穩定、最小化的結構化結果。當使用者需要單筆或批次 Route API 查詢、交通時間、距離、交通感知預測，或其他 Skill 需要路線查詢能力時使用；需要工作日展開、住家公司設定、平均通勤或公司排序時改用 commute-analyzer。
