## Description

Export deterministic Skyrim dialogue context from an original ESP/ESM/ESL with xEdit, including DIAL to child INFO relationships, quest/branch/topic metadata, prompts, conditions, responses, and structurally resolved speaker candidates. Use when xTranslator XML no longer preserves enough structure to associate INFO lines with their real dialogue topics or speakers, or when translation needs plugin-grounded dialogue context without using the xEdit GUI.
