## Description

Sweep and triage the full open-issue queue for NaturalProductMech. Fetches every open issue, checks each against the committed corpus, the inventories, the schema and the code, flags duplicates and stale figures, and assigns a priority tier (P0 something wrong that every gate passes, P1 real-but-schedulable, P2 low-severity/process/doc, P3 backlog). Produces a short ranked report; only writes to GitHub when asked. Use when the user asks to review issues, prioritize the backlog, or triage, or after a review pass files a batch of new issues.
